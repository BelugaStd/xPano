# xPano 批量任务页设计方向

## 设计依据

本方案只以 2026-08-10 当前工作区源码 `xpano-ui 2.0.1-4kfix` 的实际渲染为母版，不再使用 `docs/ui-baselines/phase-0` 历史截图。

最新版界面的稳定特征：

- 单行无边框标题栏：左侧 xPano 与当前工程，右侧环境、打开工程、主题和窗口控制。
- 全高工作区：内容直接占满标题栏与底栏之间，不增加二级全局导航。
- 单行底部 dock：工作区切换与任务进度共存，主状态永远可见。
- 默认浅色半透明液态面板；深色主题复用同一层级和 token。
- 面板圆角克制、边框低对比、阴影柔和；主操作使用品牌深蓝，进度使用数据青。
- 字号和间距偏紧凑，信息密度高但不使用传统后台式 KPI 卡片墙。

## 产品定位

- 页面：xPano 启动后的独立顶层“批量任务”页。
- 用户：需要在夜间串行处理多个 xPano 工程的采集、重建和高斯训练用户。
- 主流程：新增任务 → 在单页配置任务 → 排队 → 启动批量 → 扫描每项进度与异常 → 进入任务详情。
- 设计目标：一眼看清“现在跑什么、后面还有什么、哪里失败、还要多久”，并让新增、配置、启动和退出批量模式都在明确位置完成。

## 方案选择

### 方案 A：左侧任务导航 + 中间详情 + 右侧监控

否决。它会把任务身份重复展示两次，在 1024–1280px 宽度下挤压阶段链和进度，也会诱导加入搜索、筛选、详情抽屉等非必要功能。

### 方案 B：单一队列账本 + 复用现有底栏

采用。主区只承担“所有任务的实时扫描”，底栏承担“全局队列状态与执行动作”。这与最新版素材页的“主内容 + 底部持续状态”逻辑一致，也最容易维护。

## 桌面页面结构

### 1. 标题栏（沿用最新版，约 48px）

- 左：xPano 图标、`xPano`、分隔线、`批量任务`。
- 右：环境状态、主题切换、窗口控制。
- 批量页不显示“打开工程”；它面向多个工程，单工程入口会造成语义混乱。
- 不新增帮助、设置、通知、用户头像等入口。

### 2. 工作区（单面板）

整个工作区只放一个队列面板，不做卡片套卡片。

面板标题行：

- 左：`任务列表`、`共 6 项 · 1 项运行 · 3 项等待 · 1 项失败`。
- 右：唯一常驻主按钮 `新增任务`。
- 状态统计使用普通文本与小圆点，不拆成 KPI 卡。

任务列表：

- 表头固定，列表自身滚动。
- 每行建议高度 88–96px。
- 列结构：排序 / 任务身份 / 阶段链 / 当前进度 / 时间 / 详情入口。
- 整行可聚焦；Enter 打开配置或详情。行末只保留一个显式箭头入口。
- 排序采用拖拽把手；键盘菜单提供上移/下移，不增加两枚常驻箭头。

任务行内容：

- 身份：任务名；次行显示工程目录和素材数量摘要。
- 阶段链：`素材准备 → 对齐重建 → 高斯训练`，节点同时使用图标、文字和状态色。
- 进度：4px 细进度条、百分比、当前动作；等待任务不渲染无意义的 0% 条。
- 时间：已用时间；ETA 只在可靠时显示，否则显示 `计算中`。
- 运行行：浅品牌底色 + 3px 左标识，不做强发光。
- 失败行：一行可读错误摘要，清楚标注 `已跳过，队列继续`；展开后才显示最近日志。
- 完成行：降低视觉权重，但保留耗时和完成时间。

### 3. 空状态

- 中央只显示 `尚未添加批量任务`、一句用途说明、一个 `新增任务` 按钮。
- 不放教程、功能说明列表、示例任务或开发者术语。

### 4. 批量模式底栏（沿用最新版 dock 语法，约 58px）

- 左：队列状态，例如 `等待启动` / `正在运行第 2 / 6 项` / `已完成`。
- 中：当前任务名、全局细进度条、总百分比、总已用时间或剩余时间。
- 右：
  - 主按钮 `开始批量`；中断后同位置变为 `继续批量`。
  - 仅运行时出现危险描边按钮 `停止队列`。
  - 最右固定次按钮 `不使用任务模式`，进入现有手动工作区，不停止或清空队列。
- 不再显示手动模式的四工作区切换，因为批量页是独立顶层界面。

## 按钮清单

### 常驻

- `新增任务`
- `开始批量` / `继续批量`（同一位置、状态换文案）
- `不使用任务模式`
- 每行一个 `打开任务` 箭头

### 条件出现

- `停止队列`：仅队列运行时。
- `编辑任务`：仅草稿、失败、中断、已完成且未重新入队的任务，在行内更多菜单中。
- `重新入队`：仅失败、中断或取消任务。
- `移除任务`：仅非运行状态，在更多菜单中并二次确认。
- `展开错误/日志`：仅任务存在错误或日志时，以行内折叠入口出现。

### 明确不做

- 刷新、暂停、全选、批量删除、复制 ID、清空完成、强制跳过、独立日志窗。
- 搜索、筛选、排序下拉、KPI 卡片、左侧导航、常驻右侧详情栏。
- “保存并运行”“应用”“下一步”等与任务编辑器主动作重复的按钮。

## 单任务配置页边界

任务配置仍是独立单页，不塞进列表抽屉：

- 顶部：返回任务列表、任务名、工程目录、唯一主按钮 `保存任务`。
- 第一段：三个依赖式阶段开关，严格前缀启用。
- 主体：左侧素材轨道；右侧对齐与训练参数，两段纵向排列；高级参数折叠。
- 一个页面允许纵向滚动，但不使用多步向导和嵌套弹窗。
- 已运行任务点击后进入现有四工作区详情；批量协调器仍在后台运行。

## 视觉 token

- 亮色背景：`#F8FAFC`；亮色品牌：`#0C3868`；数据青：`#18A7B5`。
- 深色背景：`#060E18`；深色品牌：`#6EA7DB`；数据青：`#35D0D8`。
- 成功：`#16A36F`；警告：`#B7791F`；危险：`#D64550`。
- 字体：沿用现有 xPano 中文 sans 栈；计时与百分比使用现有等宽数字样式。
- 间距：4px 基础，常用 8/12/16/20/24px。
- 圆角：控制 8–10px，主面板 14–16px；不使用大胶囊卡片。
- 动效：140–260ms；只对行状态、折叠和进度变化做轻动画，支持 reduced-motion。

## 可达性与窄窗口

- 桌面主目标仍为 Windows 1024px 以上；移动稿只用于窄窗口层级压力测试，不代表移动端产品承诺。
- 1024–1199px：路径缩短，时间合并为一列，阶段节点保留文字；不隐藏错误状态。
- 更窄时：任务行改为上下两层，身份/状态在上，阶段/进度/时间在下；底栏动作保持可见。
- 任何状态都不能只依赖颜色；同时使用图标和文字。
- 主按钮至少 36px 高；窄窗口压力测试使用 44px 触控目标。
- 禁用状态必须给出原因，不能只降低透明度。
